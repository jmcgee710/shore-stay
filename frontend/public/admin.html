🏖️ Shore Stay Admin — How It Works

Edit any text or button on your Shore Stay website — no coding needed!

  • Switch pages with the dropdown at the top
  • Renter Hub tabs appear in the toolbar when that page is selected
  • Hover any element — it glows blue with a label
  • Click to select — the edit box fills with current text
  • Edit the text and click Apply Change (or Ctrl+Enter)
  • ↩ Undo in the toolbar reverts any change
  • 👁 Preview hides edit outlines to see the real look

Open in your browser at http://localhost:4174/admin.html for full interactivity.
